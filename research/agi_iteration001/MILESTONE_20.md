# Milestone 20 — Typed planning proposals and fresh test families

This experiment introduces **AI-assistant-authored recorded proposals**, not an autonomous LLM API agent. It expands the Milestone 19 hard-coded algorithm choices to a **strictly validated proposal schema** with heuristic families, nontrivial tie-breaking and bounded heuristic weights. No proposal can introduce new Python imports, shell commands, arbitrary executable code, or API spending. It reuses the deterministic weighted grid generator, but introduces new, disjoint development and holdout seeds.

The planner compares three fixed proposals: Dijkstra baseline, admissible minimum-edge Manhattan A* with a high-g tie break, and weighted 1.25 minimum-edge Manhattan A*. Selection requires 100% exact-optimal solutions on 32 development grids, then minimizes average expansions. A selected candidate and baseline are compared on 64 new seeded grids; holdout is never part of selection. Arithmetic review reruns the same implementation, not an independently written verifier.

Important: the proposal source is this assistant authoring code in a chat, **not** an autonomous model proposing candidates at runtime. The grid family is known; selected algorithms are conventional, not new model architectures. Any results are restricted to pathfinding on synthetic tasks; do not infer AGI or recursive model improvement. The new holdout is exposed after the first run. Equal algorithm evaluation counts apply only to the selection phase; the independent evaluator is not separately budgeted here. No live model, external data, paid API calls, production changes, or autonomous 55-agent fleet.
