# Prototype 006: exploratory natural-language bridge
The chat assistant authored both 12 fictional cases and structured proposals in the same session; this is not blind or independent. The baseline receives raw text, which Prototype 005 intentionally rejects; this comparison measures interface coverage, not superiority over a capable language planner. Six supported cases execute verified synthetic read procedures, six rejected cases include two permission failures. Procedure verification is not real-world completion. No live integrations, API requests, agent activation, schedules, or training. Existing 20 regression tests passed. Next gate: independent held-out tasks and an actual model-backed adapter with bounded authority, then comparative evaluation with OpenClaw. All 55 roles remain planning-only; no registry changes. Run `python compare.py` and `python -m unittest -v` in this directory.
