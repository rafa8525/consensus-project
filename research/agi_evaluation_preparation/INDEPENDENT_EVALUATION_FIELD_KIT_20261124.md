## 1. Responsibilities and separation
Project owner authorizes scope and zero-cost budget. A human custodian independent of model tuning controls the holdout, verifies rights, assigns random opaque IDs and keeps contributor identity/consent separate from content. Contributors author fresh prompts independently; neither they nor reviewers see training examples, model predictions or development pool. Two human labelers vote independently; a third independent reviewer adjudicates. Custodian must verify actual distinct people, conflicts and access permissions; an ID alone proves nothing. One custodian may also adjudicate only if independent of authors, labelers and model development. No model or agent may act as independent human reviewer. No participant is currently identified or contacted.

## 6. Reviewer scoring instructions
Rubric: design_experiment = plan a controlled test or procedure; evaluate_evidence = assess observed results or measurement quality; review_hypothesis = critique proposed explanation, assumptions or rival causes. Choose primary action, not keyword. Mark ambiguous/uncertain separately; retain every initial decision. No discussion until votes locked. Third reviewer handles all disagreements/uncertainties, records reason and excludes unresolved cases; for accepted matching votes records confirmation as required by current preflight schema. Existing annotation_quality_preflight.py requires three distinct IDs on every row, only three valid labels and no override of matching votes. If matching votes need correction or either vote is ambiguous, exclude from strict preflight, report counts/reasons and retain original votes. Never replace initial votes to improve agreement. Report full intake flow, including rejected/uncertain cases and raw agreement on all dual valid votes before exclusions as well as on accepted set; disclose selection bias. If all-dual-valid agreement or accepted preflight agreement fails >=0.80 or kappa fails >=0.70, do not proceed; undefined kappa fails. Review ambiguity rate and class representation before approval. Minimum 60 accepted, 20 per class; agreement not proof of accuracy. Custodian separately attests rights, actual independence and overlap checks. Perform cross-corpus exact, normalized and human semantic/source-family checks against all prior training, holdouts, stress sets and development tasks without exposing holdout to developers.

Before evaluation, obtain separate approval of final preregistration, independent custodian, rights and dataset manifest; confirm no model tuning after freeze. Pin existing local_inference.py and model_improvement_experiment.py at prior research commit 6d3d226b34e5317167283791953f1b0855295966, audit imports and dependencies, compute SHA-256 of code and canonical training rows; record Python version, label order and exact dataset bytes digest. Custodian verifies offline environment with no network, no API keys, no agents, read-only dataset and code. Use Python standard library only; do not run modules as CLI or call model_improvement_experiment.run(), which selects settings on old internal validation. Import fit/predict from local_inference and train_char/predict_char from model_improvement_experiment. Fit word model once on fixed existing TRAIN (18 rows); fit candidate once using same TRAIN, n=3, alpha=0.5. This deterministic fitting reconstructs frozen comparison models; no learning from new holdout and no candidate selection. For each gold row validate unique IDs, allowed labels and request length <=500, predict with both models once, never feed gold labels to prediction. Abort on malformed data, missing predictions or digest mismatch; no silent drops. Keep item-level results restricted.
Compute 3x3 confusion matrices, accuracy and precision/recall/F1 per class (zero denominators = 0), macro-F1 mean across all three fixed labels. Compare paired predictions using stratified paired bootstrap (10,000 replicates, seed 20261124; resample item indices with replacement within each gold class, preserve same resampled indices for both models; percentile 2.5/97.5 interval, specify quantile interpolation before freeze). Report paired baseline-wrong/candidate-right and reverse counts, exact two-sided McNemar binomial p-value (cap at 1; if no discordance p=1). Proposed success gate: positive lower confidence bound on candidate minus baseline macro-F1 and no class recall decrease >0.10; otherwise inconclusive/regression. Report small-sample limitations, source clustering, all exclusions, metrics and protocol deviations. No automatic promotion. This is narrow classifier evidence, not AGI. Any real run requires separate approval; no executable evaluator added in this package.
