AI Consensus — Google Drive Backup Integration

AI Consensus is a personal, noncommercial automation project. This page describes its planned Google Drive backup integration and related Google authorization request.

Purpose

The integration is intended to let the project owner authorize the application to create, locate, verify, and restore backup archives stored in the owner's Google Drive. Backup archives are intended to be encrypted before upload. The integration is under development; this page does not represent that remote backups or automatic recovery are already operating.

Google Drive permissions

The backup application requests the Google Drive drive.file scope, which limits access to files created or explicitly opened with the application. It is not intended to request unrestricted access to all of the account's Google Drive files.

Personal use and access

The service is designed for authorization by its owner rather than for use by the general public. It does not provide a public Google Drive file browser or public backup download service.

Privacy and control

Read the privacy policy for information about intended data handling, credentials, and revoking access.
